# DexiType

DexiType is a free typing tutor that runs in the browser on Windows, Mac and Linux. It is meant for anyone, including someone who has never used a keyboard before.

It has 11 stages, from Keyboard Basics (where to put your hands and which finger presses which key) up to Pro speed. Each stage opens only after the one before it is cleared. There are also typing tests, three games and a statistics page.

Progress is saved in your browser on your own computer. Adults (18+) can choose to save their progress online with Google sign-in.

Live site: https://dexitype.github.io/
